# delos-reyes-alexander-daniel-frontend

## Laboratory Exercise No. 6: Product Management System (Frontend)
A modern full-stack Single Page Application (SPA) built with **React.js** and **Vite** communicating with the **LavaLust REST API** and **Aiven Cloud MySQL**.

### Features
- **User Authentication**: Secure token-based authentication (JWT Bearer Token).
- **Product Management (CRUD)**:
  - Display Products
  - Add Product
  - Edit Product
  - Delete Product
- **Search & Metrics**: Live search filtering and real-time inventory statistics.
- **Protected Endpoints**: Communicates securely with the LavaLust REST API backend.
